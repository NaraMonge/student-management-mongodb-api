Módulo de Información

Esta aplicación fue construida como interfaz web para consumir el API local. Utiliza Bootstrap para el diseño visual y jQuery con AJAX para comunicarse con el backend.

  • HTML para la estructura de la página.
  • Bootstrap para diseño responsivo.
  • jQuery y AJAX para consumir el API.
  • API en Node.js, Express y MongoDB.
Para que la página funcione, primero debe estar ejecutándose el API con npm run dev.
